# Sentinel Dashboard

React 19 + TypeScript + Vite + Tailwind v4 frontend for Sentinel.

- `npm run dev` — live mode (proxies `/api` + `/health` to `:8000`)
- `npm run dev:demo` — demo mode (seeded replay engine, no backend)
- `npm test` / `npx tsc -b` / `npm run lint` — CI gates

See the repo root [README](../README.md) for the full system, and
[DESIGN.md](./DESIGN.md) for the dashboard's visual language.
